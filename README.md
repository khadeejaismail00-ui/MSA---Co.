# MSA & Co. — Next.js Website

This project converts the supplied MSA & Co. static website into a Next.js App Router project while preserving the original visual layout, navigation, imagery, video, Tailwind classes and client-side interactions.

## Pages
- `/` — Home
- `/about` — About
- `/services` — Services
- `/team` — Team
- `/contact` — Contact

## Run locally
```bash
npm install
npm run dev
```

For production:
```bash
npm run build
npm start
```

Set `NEXT_PUBLIC_SITE_URL` to the final HTTPS website URL before deployment so canonical URLs, sitemap and structured data use the live domain.

## SEO included
- Page-specific titles and meta descriptions
- Canonical URLs
- Open Graph and Twitter metadata
- Robots metadata
- XML sitemap and robots.txt generated by Next.js
- AccountingService JSON-LD structured data
- Semantic language declaration and crawlable server-rendered page content
- Optimized local asset paths under `public/`
